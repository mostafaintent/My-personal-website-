# وبسایت شخصی

سایتی برای نوشتن مقاله‌ی رایگان، با حساب کاربری، نظرات، و امکان انتشار
مقاله‌های بلند/ترجمه‌ها/کتاب‌ها به‌صورت محتوای ویژه — قابل خرید تکی یا با
اشتراک ماهانه/سالانه. ساخته‌شده با Next.js + TypeScript + Tailwind CSS +
Supabase، از نظر طراحی الهام‌گرفته از [themarginalian.org](https://www.themarginalian.org).

## راه‌اندازی (قدم‌به‌قدم)

سایت بدون یک پروژه‌ی رایگان Supabase کار نمی‌کند (چون مقاله‌ها، حساب‌های
کاربری، خریدها و نظرات همه آنجا ذخیره می‌شوند). این کار را فقط یک‌بار انجام
می‌دهید:

1. به [supabase.com](https://supabase.com) بروید، یک حساب رایگان بسازید و
   یک پروژه‌ی جدید بسازید (یک اسم و رمز عبور دیتابیس می‌خواهد — رمز را
   جایی نگه دارید).
2. داخل پروژه، از منوی سمت چپ به **SQL Editor** بروید، فایل
   `supabase/schema.sql` این ریپو را کامل کپی کنید، در SQL Editor پیست کنید
   و Run بزنید. این کار همه‌ی جدول‌ها را می‌سازد.
3. برای این‌که خودتان مدیر (ادمین) سایت باشید:
   - اول یک‌بار از داخل خودِ سایت (بعد از اجرا) در `/signup` با ایمیل خودتان
     ثبت‌نام کنید.
   - بعد به SQL Editor برگردید و این خط (آخر فایل `schema.sql`) را با
     ایمیل خودتان اجرا کنید:
     ```sql
     update profiles set role = 'admin'
     where id = (select id from auth.users where email = 'شما@example.com');
     ```
4. (اختیاری) برای دیدن سایت با چند مقاله‌ی نمونه، محتوای فایل
   `supabase/seed.sql` را هم در SQL Editor اجرا کنید.
5. در پروژه‌ی Supabase به **Project Settings → API** بروید و سه مقدار
   `Project URL`، `anon public key` و `service_role key` را بردارید.
6. فایل `.env.local.example` را کپی کنید به یک فایل جدید به اسم
   `.env.local` و مقادیر بالا را داخلش بگذارید.
7. اجرا:
   ```bash
   npm install
   npm run dev
   ```
   سپس http://localhost:3000 را باز کنید. وقتی سایت را جایی مثل Vercel
   دیپلوی می‌کنید، همین سه مقدار را در تنظیمات Environment Variables آنجا
   هم وارد کنید.

## ساختار پروژه (برای توسعه‌ی بعدی)

- `supabase/schema.sql` — تعریف کامل جدول‌ها و دسترسی‌ها (RLS).
- `supabase/seed.sql` — چند مقاله‌ی نمونه (اختیاری).
- نام سایت، بیوگرافی نویسنده، بنر و لینک‌های شبکه‌های اجتماعی — همه از پنل مدیریت (`/admin/settings`) قابل‌ویرایش‌اند و در جدول `site_settings` ذخیره می‌شن.
- `lib/articles.ts` — خواندن مقاله‌ها از دیتابیس (نه فایل — نوشتن مقاله از پنل مدیریت انجام می‌شود).
- `lib/payments/providers.ts` — سه روش پرداخت (درگاه بانکی، PayPal، ارز دیجیتال). فعلاً فقط UI‌شان آماده است (`available: false`)؛ برای فعال‌کردن هرکدام، `createCheckout` را به API واقعی همان درگاه وصل کنید.
- `lib/payments/plans.ts` — قیمت طرح‌های اشتراک ماهانه/سالانه (فقط نمایشی، تا وقتی پرداخت واقعی وصل شود).
- `lib/payments/access.ts` — تابع `hasAccess` که بر اساس خرید تکی یا اشتراک فعال، دسترسی به مقاله‌ی ویژه را چک می‌کند.
- `app/admin/` — پنل مدیریت: نوشتن/ویرایش/حذف مقاله، مدیریت نظرات، و اعطای دستی دسترسی (برای وقتی پول را دستی — مثلاً کارت‌به‌کارت — دریافت کردید).
- `app/account/` — صفحه‌ی «حساب من»: مقاله‌های خریداری‌شده، وضعیت اشتراک، نظرات کاربر.
- `app/login`, `app/signup` — ورود و ثبت‌نام.
- `components/` — قطعات مشترک UI.

## نکته‌ی مهم درباره‌ی پرداخت واقعی

درگاه‌های پرداخت (بانکی/PayPal/کریپتو) فعلاً فعال نیستند — فقط رابط
کاربری‌شان آماده است. تا وقتی وصلشان نکرده‌اید، از `/admin/access` برای
فعال‌سازی دستیِ دسترسی کاربرها (بعد از دریافت پول به‌هر روشی) استفاده کنید.

## مراحل بعدی پیشنهادی

1. نام سایت، بیوگرافی و لینک‌های واقعی از پنل مدیریت (`/admin/settings`)
2. نوشتن مقاله‌های واقعی از پنل مدیریت (`/admin/articles/new`)
3. اتصال یک یا چند درگاه پرداخت واقعی (`lib/payments/providers.ts`)
4. تنظیم ایمیل تأیید حساب در Supabase (Authentication → Email Templates) اگر خواستید ایمیل فارسی/برندشده بفرستید
