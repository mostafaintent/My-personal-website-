# وبسایت شخصی

سایتی برای نوشتن مقاله‌ی رایگان، با امکان انتشار برخی مقاله‌های بلند/ترجمه‌ها/کتاب‌ها به‌صورت محتوای ویژه (پولی). ساخته‌شده با Next.js + TypeScript + Tailwind CSS، از نظر طراحی الهام‌گرفته از [themarginalian.org](https://www.themarginalian.org).

## اجرا روی سیستم شخصی

```bash
npm install
npm run dev
```

سپس آدرس http://localhost:3000 رو باز کنید.

## ساختار پروژه (برای توسعه‌ی بعدی)

- `content/articles/*.mdx` — هر فایل یک مقاله است. نوشتن مقاله‌ی جدید یعنی اضافه‌کردن یک فایل `.mdx` جدید در همین پوشه. بالای هر فایل یک بخش frontmatter هست:
  ```
  ---
  title: "عنوان مقاله"
  date: "2026-08-08"
  excerpt: "خلاصه‌ی کوتاه"
  tags: ["تگ۱", "تگ۲"]
  premium: false        # true یعنی مقاله ویژه/پولی است
  type: "article"        # article | translation | book
  priceUSD: 5             # فقط برای مقاله‌های ویژه
  priceIRR: 250000        # فقط برای مقاله‌های ویژه (به ریال)
  ---
  ```
  بعد از `---` دوم، متن مقاله با فرمت Markdown نوشته می‌شود.

- `lib/site-config.ts` — نام سایت، شعار، بیوگرافی نویسنده و لینک‌های شبکه‌های اجتماعی. برای تغییر نام سایت یا معرفی خودتان، همین فایل کافیست.

- `lib/payments/` — ساختار سه روش پرداخت (درگاه بانکی، PayPal، ارز دیجیتال). فعلاً هرسه فقط رابط کاربری‌شان ساخته شده (`available: false`) و پرداخت واقعی انجام نمی‌دهند. برای فعال‌کردن هرکدام در آینده، فایل `lib/payments/providers.ts` را ویرایش کنید و `createCheckout` را به API واقعی همان درگاه وصل کنید — بقیه‌ی سایت بدون تغییر باقی می‌ماند.

- `lib/payments/access.ts` — تابع `hasAccess` که فعلاً همیشه `false` برمی‌گرداند (چون هنوز سیستم حساب‌کاربری/خرید وجود ندارد). وقتی احراز هویت و ثبت خرید اضافه شود، این تابع باید واقعی بشود.

- `app/` — صفحات سایت: خانه (`page.tsx`)، آرشیو مقاله‌ها (`articles/page.tsx`)، صفحه‌ی هر مقاله (`articles/[slug]/page.tsx`)، درباره (`about/page.tsx`)، حمایت (`support/page.tsx`).

- `components/` — قطعات مشترک UI (هدر، فوتر، کارت مقاله، بخش قفل محتوای ویژه، دکمه‌های پرداخت).

## مراحل بعدی پیشنهادی

1. نام سایت، بیوگرافی و لینک‌های واقعی در `lib/site-config.ts`
2. جایگزینی مقاله‌های نمونه با نوشته‌های واقعی
3. اتصال یک یا چند درگاه پرداخت واقعی (`lib/payments/providers.ts`)
4. اضافه‌کردن احراز هویت و پایگاه‌داده برای مدیریت خریدهای واقعی (`lib/payments/access.ts`)
